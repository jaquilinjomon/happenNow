Project Description
HappenNow is a real-time event discovery and management platform designed to bridge the gap between event organizers and attendees. It allows users to browse upcoming events, view details, and manage their schedules seamlessly.

The Problem Statement
Finding local or niche events often involves digging through fragmented social media posts or outdated websites. Organizers struggle to reach their target audience effectively, while users often miss out on interesting "happening now" opportunities due to a lack of centralized, real-time information.

The Solution
We built a centralized hub with a clean UI where events are categorized and easily searchable. By leveraging a modern tech stack, we ensure fast loading times, responsive design for mobile users, and a streamlined flow for both discovering and listing events.

System Architecture:
The application follows a client-server architecture. The Frontend is built with Next.js and React, styled with Tailwind CSS. It communicates with a backend/database (or static data files) to fetch event details and renders them dynamically.

Application Workflow:

User lands on the Homepage.

User filters/searches for specific events.

User selects an event to view full details.

(Optional) User interacts with "Interested" or "Register" buttons.
